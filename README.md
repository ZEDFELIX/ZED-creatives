# ZED Creatives — Brand & Design Studio

**Canonical ZED Creatives website repository.**

ZED Creatives is Felix Simon's design studio and the primary home for the brand website, services, portfolio, shop and supporting client experience.

## Direction

Design-first, premium, editorial and human — focused on branding, graphic design, digital experiences and commerce.

## Pages

- Marketing: landing page, services, portfolio, pricing, FAQ, testimonials, blog, careers, contact and legal
- Commerce: shop, product, cart, checkout, orders and wishlist
- Account: login and profile
- Admin: content editor
- Utility: 404

## Deployment

This is the canonical ZED Creatives codebase. The similarly named `zed-creatives-1` repository is a legacy copy and should not receive new feature work.

## Current architecture

The site is currently static/local-first. Admin and account data that uses localStorage remains local until a production backend is connected.
